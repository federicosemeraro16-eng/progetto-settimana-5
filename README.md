# Bloom

Questo è il progetto della settimana 5: una landing page per **Bloom**, uno studio di design (inventato) che si occupa di identità visiva, web design e motion graphic.

## Cosa ho fatto

- Ho costruito la pagina **mobile-first** e poi l'ho adattata a tablet e desktop con le media query (`577px` e `1200px`).
- L'**header** resta fisso in alto e quando scorro la pagina diventa verde.
- Ho aggiunto la **dark mode**: con il pulsante nell'header la pagina cambia tema e l'icona passa da luna a sole.
- Al caricamento il testo della **hero** entra con una piccola animazione dal basso.
- Le sezioni **Lavori**, **Servizi** e **Team** sono fatte con delle card che si sistemano da sole in base alla larghezza dello schermo.
- Nella sezione **Dicono di noi** c'è un carousel di recensioni fatto solo con CSS; se ci passo sopra con il mouse si ferma.
- Il pulsante **Richiedi preventivo** apre una modale con un form (nome, email, servizio e messaggio).
- Ho cercato di curare l'**accessibilità**: tag semantici, `label` collegate ai campi, `aria-label` sui pulsanti e sui link che hanno solo un'icona.

## Cosa ho usato

- HTML
- CSS (Flexbox, nesting, media query, transition e animation)
- JavaScript (eventi `click` e `scroll`, `classList`)
- Font Awesome per le icone

## Cosa ho imparato

Con questo progetto ho capito meglio come funzionano i selettori con il nesting (soprattutto quando serve il `&`), come gestire il layout delle card con flex e come cambiare l'aspetto della pagina aggiungendo una classe con JavaScript.
